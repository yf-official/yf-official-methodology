# 共同方法导览

[English](methodology.md) · 简体中文 · [返回论文集](../README.zh-CN.md)

本页是对 [DeckStage](../papers/deckstage/README.zh-CN.md) 与 [IconLab](../papers/iconlab/README.zh-CN.md) 的编辑性归纳，连接两篇论文中的工程选择，不构成新的实验结论。

## 从问题走到可检查的输出

```text
原始资源 + 明确约束
        ↓
规范状态与几何模型
        ↓
交互修改与目标渲染
        ↓
输出结果 + 独立检查
```

两篇论文都在追问：表示方式发生变化时，哪些含义必须保持不变？DeckStage 连接图稿、实体尺寸、场景投影和最终像素；IconLab 连接设计坐标、显示手势、撤销历史和输出尺寸。

## 反复出现的五个选择

| 方法选择 | DeckStage | IconLab |
| --- | --- | --- |
| 保留原始资源 | 不可变源图像与单张包装图集 | 图稿资源与可编辑参数分离 |
| 声明坐标含义 | 图稿、物理牌面、场景、输出与世界坐标 | 规范归一化坐标、显示反射与目标像素 |
| 共享几何模型 | 平面单应变换、局部蒙版与牌盒相机 | 连续底板与规范仿射参数 |
| 区分编辑与输出 | 素材分配和姿态存入场景，从源素材导出 | 即时预览、延后提交历史、冻结快照导出 |
| 证据与结论对应 | 精确裁切检查、参考诊断与合成拟合实验 | 源码检查、代数恒等式、合成覆盖率与坐标实验 |

## 一个具体例子：移动图像

拖动图像修改的是位置参数，不应覆盖源文件、悄悄改变裁切，或让导出结果依赖当前预览缩放。

在 DeckStage 中，逆映射决定哪个可见牌面接收图稿，相机与牌面局部几何决定渲染位置。在 IconLab 中，显示位移从手势起始状态换算为规范单位，一次有意义的编辑形成一次撤销事务，导出使用保存的设计状态。

同一个用户动作因此涉及多个需要写清楚的约定：坐标转换、状态归属、命中检测、事务边界和导出快照。

## 读实验结果时的四个问题

1. **测试对象是什么？** 公式、合成样例、应用渲染器和人的感知判断需要不同的证据。
2. **单位与条件是什么？** 像素误差依赖参考尺寸；超采样结果依赖相位、形状、参考密度与滤波核。
3. **共享到哪一层？** 共用状态可以表达相同几何意图，却不保证不同后端逐像素一致。
4. **还有什么未测量？** 拟议验收阈值、延迟目标和审美收益应与已经观察到的结果明确区分。

## 如何用到下一个项目

先写清源资源、规范参数、坐标单位和不变量，再描述交互如何修改状态、导出如何读取状态。选择能够独立失败的检查：用不对称标记检查方向，用已知出血带检查裁切，用中断手势检查撤销，用冻结状态检查多尺寸包的一致性。
