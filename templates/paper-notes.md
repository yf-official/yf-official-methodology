# Paper-note template / 论文导读模板

[Contribution guide](../CONTRIBUTING.md) · [中文贡献指南](../CONTRIBUTING.zh-CN.md)

Copy the outline below into separate English and Chinese notes. Replace every instruction before publication. Paths in paper notes must be relative to their own directory; use the existing paper pages as navigation examples.

将下方提纲分别用于英文与中文导读，发布前替换所有说明文字。链接相对于导读文件所在目录，可参考已有论文的导航。

```text
# Project name / 项目名

Language switch and link back to the collection / 语言切换与返回论文集

## Publication / 出版信息
Full original title; label translated title / 完整原题，标明译名
Actual author, date, language, page count, publication status / 作者、日期、语言、页数、出版状态
Versioned PDF, release, verified project URL, BibTeX key / 版本化 PDF、发布页、已核实项目链接、引用键
Clarify the relationship between notes and manuscript / 说明导读与原稿的关系

## The problem / 论文解决什么问题
Concrete task, constraints, and scope / 具体任务、约束与范围

## Method / 核心方法
Three to five steps, with assumptions and units / 三至五步，注明假设和单位

## Section map / 章节地图
Actual section identifiers and reading goals / 真实章节编号与阅读目的

## Evidence / 已有证据
Tested object, conditions, sample count, metrics, results, limitations / 对象、条件、样本量、指标、结果及局限
Distinguish proposed targets from measured results / 区分拟议目标与测量结果

## Open questions / 开放问题
Implementation gaps and unmeasured properties / 实现缺口与未测量性质
Available reproduction links; disclose missing materials / 可用复现材料，说明缺失内容

## Citation and rights / 引用与权利
Actual bibliographic details and original rights statement / 真实引用信息与原始权利声明
```
